# setup-app-practice

## 概要
COACHTECH 教材 Tutorial 9-1「環境構築ハンズオン」で作成した成果物です。
Laravel Sail と Docker を使って、Tutorial 9〜10 のハンズオンで使う開発環境を構築しました。

## 使用技術
- PHP 8.2
- Laravel 10.0
- Laravel Sail（Docker Compose）
- MySQL, phpMyAdmin

## 学んだこと
- 環境構築の流れ
- エイリアス設定の有難み

## 動作確認
ブラウザから[http://localhost]にアクセスして確認しました。
